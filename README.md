# Tangentbordsträning

Ett enkelt verktyg gjort för barn i Hello World-programmet, för att lära sig hitta rätt på ett svenskt tangentbord och se hur man skriver symboler som inte syns direkt på tangenterna.

## Vad det gör

- Visar ett svenskt tangentbord på skärmen, både för PC och Mac
- Klicka på en symbol (till exempel `"`, `@`, `{`) så visas vilken tangent eller tangentkombination som skriver den
- Tryck på en riktig tangent så tänds samma tangent på skärmen
- Presentationsläge som visar vald tangent eller symbol i stort format, bra för genomgångar
- Kopiera-knapp för att snabbt kopiera en symbol
- Fullskärmsläge

## Filer

- `index.html` – PC-layout (svensk)
- `mac.html` – Mac-layout (svensk)

Sidorna länkar till varandra via en knapp uppe i hörnet.

## Så här används det

1. Öppna verktyget här: https://yoosseph.github.io/keyboard-helper/index.html
2. Klicka på en symbol för att se vilken tangent/kombination som ger den
3. Eller tryck på en tangent på riktigt för att se den lysa upp på skärmen
4. Klicka "Rensa" för att börja om
5. Slå på Presentation för större text vid genomgång

## Teknik

Bara HTML, CSS och JavaScript. Inget behöver installeras.
